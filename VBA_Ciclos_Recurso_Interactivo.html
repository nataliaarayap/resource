¿Qué es Cells(f, c)?

Cada celda de Excel tiene una dirección numérica. Cells(f, c) apunta exactamente a la celda en la fila f y columna c. Mueve los controles y observa qué celda se resalta en la hoja.

3
Ciclo + condicional + acumulador

El ciclo recorre la tabla de MediRed fila por fila. En cada fila evalúa si el médico cumple la meta de atenciones, acumula el total y escribe el estado directamente en la hoja. Ejecuta paso a paso para ver cómo interactúan ciclo, condicional y acumulador.

Código VBA
Option Explicit Sub AnalizarMedicos() Dim f As Integer Dim nombre As String Dim atenc As Integer Dim total As Integer Dim estado As String f = 2 : total = 0 Do While Cells(f, 1).Value <> "" nombre = Cells(f, 1).Value atenc = Cells(f, 2).Value total = total + atenc If atenc >= 50 Then estado = "Meta cumplida" Else estado = "Bajo meta" End If Cells(f, 3).Value = estado f = f + 1 Loop Cells(8, 2).Value = total End Sub

Doble ciclo — f y c se mueven juntos

En el doble ciclo, f avanza lento (una vez por médico) y c avanza rápido (recorre todos los meses dentro de cada médico). Ejecuta paso a paso y observa cómo la celda resaltada se mueve primero hacia la derecha y luego baja una fila.

Código VBA
Option Explicit Sub TotalesSemestrales() Dim f As Integer Dim c As Integer Dim total As Integer ' Ciclo externo: médico por médico For f = 2 To 11 total = 0 ' Ciclo interno: mes por mes For c = 3 To 8 total = total + Cells(f, c).Value Next c Cells(f, 9).Value = total Next f End Sub
